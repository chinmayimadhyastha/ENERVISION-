# ENERVISION Backend — Production REST API

Flask REST API serving the frozen ENERVISION **daily** renewable-generation forecasting artifacts. It exposes real plant metadata, observed daily generation and weather, daily model forecasts, model metrics, local explainability, confidence intervals, database persistence, and descriptive analytics.

---

## 1. Scope & Forecasting Contract

| Property | Value |
|---|---|
| Forecast frequency | **daily** |
| Target variable | `DailyGeneration_MU` |
| Target unit | **MU/day** (Million Units / day) |
| Forecast horizon | 1–7 future **days** (default 3) |
| Hourly forecasting | **Not supported**; no hourly model or dataset exists |
| Confidence intervals | Scientifically grounded (Ensemble tree quantiles for RF; test-set residual RMSE for LSTM) |
| Future weather | Supported via Open-Meteo live provider (when coordinates and network available) or strict test mode |
| Database | SQLAlchemy relational storage (`data/enervision.db` SQLite default, PostgreSQL ready) |

All data returned is loaded from committed CSV/report files and database tables; all predictions are generated by the real trained ML models.

## 3. Endpoints

All endpoints are hosted under `/api`.

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Service health, readiness, loaded models, data coverage |
| `GET` | `/api/plants` | Plant catalogue with optional `type` and `district` filters |
| `GET` | `/api/plants/<plant_id>` | Plant metadata, coordinates, latest and recent generation |
| `GET` | `/api/generation-history` | Observed daily generation (fleet, type, or plant scope) |
| `GET` | `/api/generation/<plant_id>` | Route alias for plant-specific generation history |
| `GET` | `/api/weather` | Observed historical daily weather for a plant |
| `GET` | `/api/weather/<plant_id>` | Route alias for plant-specific historical weather |
| `GET` | `/api/forecast` | Daily forecast (`plant_id`, `model`, `horizon`, `base_date`, `include_confidence`, `include_explanation`) |
| `POST` | `/api/forecast` | Daily forecast with JSON body (`{"plant_id": "...", "model": "...", "horizon": 3, "include_confidence": true}`) |
| `GET` | `/api/forecast/<plant_id>` | Plant-scoped daily forecast endpoint |
| `GET` | `/api/models` | Registry of all trained and evaluated models |
| `GET` | `/api/models/<model_id>` | Model metadata, architecture, features, and evaluation metrics |
| `GET` | `/api/model-performance` | Verified evaluation metrics (MAE, RMSE, R²) with provenance separation |
| `GET` | `/api/feature-importance` | Global Random Forest impurity feature importance |
| `GET` | `/api/explainability/<plant_id>` | Local decision tree feature contributions for plant's latest state |
| `GET` | `/api/dashboard` | Fleet summary for the latest observed date (capacity, generation, weather) |
| `GET` | `/api/analytics` | Descriptive generation analytics across plant, type, or fleet |

## 4. Setup & Running the Backend

### Environment Setup

```powershell
# 1. Activate virtual environment
.\.venv\Scripts\Activate.ps1

# 2. Run backend
python backend/app.py
```

Defaults:
- Host: `0.0.0.0`
- Port: `5000`
- Base URL: `http://localhost:5000`

### Environment Variables (.env)

| Variable | Default | Purpose |
|---|---|---|
| `ENV` | `development` | Deployment environment (`development`, `production`) |
| `PORT` | `5000` | HTTP listening port |
| `DATABASE_URL` | `sqlite:///data/enervision.db` | Relational database connection string |
| `FUTURE_WEATHER_PROVIDER` | `open-meteo` | Weather provider (`open-meteo` or `unavailable`) |
| `CORS_ORIGINS` | `http://localhost:5173,http://localhost:5174` | Allowed frontend origins |

---

## 5. Frontend Integration

To connect the React/Vite dashboard to this live backend:

1. In the `frontend/` directory, create or edit `.env`:
   ```bash
   VITE_API_BASE_URL=http://localhost:5000
   ```
2. Start the frontend:
   ```bash
   cd frontend
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser. The frontend will communicate directly with the live Flask API on port 5000.
