# Data Dictionary

| Column | Type | Description |
|---------|------|-------------|
| Date | Date | Observation Date |
| District | String | Karnataka District |
| Latitude | Float | District Latitude |
| Longitude | Float | District Longitude |
| Temperature | Float | Daily Average Temperature (°C) |
| Humidity | Float | Relative Humidity (%) |
| WindSpeed | Float | Daily Average Wind Speed (m/s) |
| GHI | Float | Global Horizontal Irradiance (kWh/m²/day) |
| Year | Integer | Year |
| Month | Integer | Month |
| Day | Integer | Day |
| DayOfYear | Integer | Day Number in Year |
| Week | Integer | Week Number |
| Season | String | Season Category |
| SolarPotential | Float | Estimated Solar Potential |
